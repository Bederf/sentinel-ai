# SENTINEL Reference Architecture

## Layers

- Experience layer: web UI, technician workflows, operator interfaces
- Application layer: API services, AI routing, approval and safety workflows
- Data layer: operational records, audit trails, model feedback data
- Platform layer: containers, observability, infrastructure services
- Governance layer: policy controls, risk controls, compliance evidence

## Control Backbone

- Quality gates + mode policy
- Tier routing + approval controls
- Audit logging + incident response
- AI governance mappings (ISO 42001, NIST AI RMF, EU AI Act)
