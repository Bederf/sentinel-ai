# SENTINEL Architecture Repository

This directory formalizes SENTINEL architecture assets in a TOGAF-aligned structure.

## Structure

- `principles/` - architecture principles and decision guardrails
- `standards/` - technology and design standards catalog
- `reference/` - target and reference architecture views
- `governance/` - ADM mapping, board model, approval controls
- `landscapes/` - baseline/current-state architecture views
- `roadmaps/` - transition and migration plans
