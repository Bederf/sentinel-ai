Notifications Module

Unified Alert & Event Management

Platform

Overview

The Notifications Module is the central hub for all alerts, warnings, and system events across SENTINEL. It aggregates events from every module, applies intelligent routing rules to ensure the right person gets the right alert at the right time, and maintains a complete audit trail for compliance and operational accountability.

Capabilities

  • Unified alert inbox — all events from all modules in one place
  • Priority tiers: Critical, High, Medium, Low, Info — each with configurable escalation paths
  • Multi-channel routing: Telegram (primary), email, SMS (via third-party), browser push
  • Alert suppression windows — scheduled mute periods for maintenance windows
  • Routing rules engine — route alerts by equipment type, site, severity, or time-of-day
  • Alert acknowledgment and resolution workflow with forced escalation timers
  • Alert correlation — suppresses duplicate storms from related equipment
  • Full audit log of all notification events, routing decisions, and acknowledgments

Routing Rules

Alerts are routed using configurable rules that check: module type → equipment → site → severity → time window → recipient. Rules can be created in Settings > Alert Routing. Example: "Fire alarms → Site Manager + Security → always, 24/7".
