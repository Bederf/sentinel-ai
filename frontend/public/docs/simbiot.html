SIMBIOT Module

Universal Protocol Adapter — Zero-Code Equipment Integration

Platform

Overview

SIMBIOT (SENTINEL Message Bus Interface for Building Automation) is the universal adapter layer that allows SENTINEL to communicate with any building system — regardless of the underlying protocol (BACnet/IP, MQTT, Modbus, DALI-2, KNX). It provides a unified data model so all equipment can be managed, controlled, and queried through a single interface — without writing protocol-specific code for each integration.

Capabilities

  • Protocol translation — BACnet/IP ↔ SENTINEL native format, MQTT ↔ BACnet, Modbus ↔ MQTT
  • Auto-discovery — probes connected devices and auto-populates the equipment registry
  • Equipment registry sync — discovered equipment is created and maintained in SENTINEL's asset DB
  • Write-back support — send setpoint commands through the SIMBIOT adapter to BACnet devices
  • Data normalization — raw BACnet/DALI/Modbus values normalized to SENTINEL units (°C, %, kW)
  • Connection policy — configurable retry, timeout, and fallback behavior per site
  • SIMBIOT Bridge agent — runs on the edge SBC; handles protocol negotiation locally

SIMBIOT Bridge

The SIMBIOT Bridge is a lightweight edge agent (runs on Raspberry Pi or similar SBC) that connects to the building network and translates protocols to MQTT for SENTINEL cloud ingestion. One Bridge handles all equipment at a site — no per-equipment configuration needed.
