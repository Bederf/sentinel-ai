Fire Module

Fire Detection, Alarm Integration & Emergency Response Coordination

Building System

Overview

The Fire Module provides read-only monitoring of fire detection and alarm systems. It aggregates events from fire alarm control panels (FACP), smoke detectors, heat detectors, manual call points, and suppression system status panels. Fire events automatically trigger emergency protocols: HVAC smoke control sequencing, lift management for fireman service, and emergency notification routing to facilities managers.

Safety Notice: SENTINEL Fire Module is for monitoring and coordination only — it does not replace the fire alarm control panel (FACP) or any life-safety function. All fire system control remains with the registered fire installation and local fire officer. SENTINEL Fire Module does not control any fire suppression equipment.

Capabilities

  • Fire alarm event ingestion from BACnet/IP or dry-contact interface to FACP
  • Smoke detector and heat detector zone mapping to building floors/zones
  • Manual call point (MCP) event logging and location tracking
  • Suppression system status — sprinkler pump running, water tank level, zone isolation valve state
  • Fire zone status panel — one-view dashboard of all fire zones
  • Emergency protocol triggering — auto-zones HVAC dampers to smoke control mode on fire alarm
  • Lift/fire elevator management — recalls elevators to designated floor on fire alarm
  • Incident log for fire events with timestamp, zone, and operator acknowledgment

Integration

Fire reads from BACnet/IP or dry-contact relay interfaces. Works with HVAC (smoke control sequences), Elevator/Lift integration (fireman recall), Notifications (alerts to facilities team), and Logging (audit trail of all fire events and responses).
