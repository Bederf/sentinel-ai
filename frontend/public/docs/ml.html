ML Module

Machine Learning — Predictive Analytics & Model Training

Platform

Overview

The ML Module is the intelligence engine of SENTINEL. It runs continuous model training in the background, generates predictive alerts, and provides anomaly detection across all building systems. Models are trained per equipment type (AHU, Chiller, FCU, VAV, etc.) using historical telemetry, and are continuously retrained as fresh data arrives.

Capabilities

  • Background model training pipeline — runs on a configurable schedule without impacting BMS performance
  • Per-equipment-type models: AHU, Chiller, FCU, VAV, Lighting circuits, Solar inverters
  • Predictive maintenance — forecasts equipment degradation before failure occurs
  • Anomaly detection with contextual enrichment (weather, occupancy, time-of-day)
  • Drift detection — alerts when live data deviates from model predictions
  • Fleet-wide benchmarking — compares site performance against portfolio averages
  • Model retraining triggers based on prediction confidence decay or manual override events

Integration Points

ML Module consumes telemetry from all building system modules. Its outputs feed into AI Recommendations, KPI, Fleet ML, and Digital Twin. It receives feedback from Maintenance (work order outcomes) and Aegis (operator overrides) to improve model accuracy.
