Integrations Module

External System Connectivity & Health Monitoring

Platform

Overview

The Integrations Module provides a unified view of all external system connections that SENTINEL depends on — BACnet gateways, DALI lighting bridges, Desigo CC servers, MQTT brokers, and third-party APIs. It continuously monitors the health of each connection and alerts operators when a data source goes offline or degrades.

Capabilities

  • Real-time connection health for all integrations (BACnet, DALI, Niagara, MQTT, Modbus)
  • Automated reconnection attempts on connection loss with exponential backoff
  • Data freshness monitoring — alerts when expected telemetry stops arriving
  • Latency and throughput metrics per integration channel
  • SIMBIOT universal adapter — bridges any BACnet/IP or MQTT device without custom code
  • Integration configuration UI in Settings — add/remove/reset connections per site
  • Audit log of all connection state changes and reconnection events
