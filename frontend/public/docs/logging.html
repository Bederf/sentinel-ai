Logging Module

Audit Trail, Event Logs & Compliance Logging

Platform

Overview

The Logging Module captures every significant event, action, and state change in SENTINEL — providing a complete, tamper-evident audit trail required for regulatory compliance (POPIA, ISO 27001), operational accountability, and incident investigation. All logs are immutable and timestamped with millisecond precision.

Capabilities

  • Immutable audit log — all operator actions, system events, and AI recommendations logged
  • Log retention policy enforcement — configurable retention (30d, 90d, 1y, 7y) per log category
  • Full-text search across all log entries with timestamp and equipment filtering
  • Automated compliance reports: POPIA data access reports, access frequency reports
  • Gateway log forwarding — centralizes logs from remote site Bridge agents
  • Export logs as CSV or JSON for external SIEM integration (Splunk, Elastic, Microsoft Sentinel)
  • Log compression and archival to object storage for long-term retention
  • Operator session tracking — login/logout events, role changes, permission escalations
