Security Module

Access Control, CCTV & Intruder Detection Monitoring

Building System

Overview

The Security Module integrates with building access control systems (iCCure, Bosch, Axis), CCTV cameras, and intruder alarms to provide a unified security monitoring dashboard. It correlates access events with occupancy and HVAC activity to detect anomalies (e.g., after-hours access to areas with no corresponding HVAC activity). Security alerts are routed through the Notifications Module with high priority.

Capabilities

  • Access event monitoring — card reader activations, door open/close, alarm events
  • CCTV camera status — online/offline, recording status per camera
  • Intruder alarm zone status — armed/disarmed, active alarm zones
  • Security patrol route monitoring — guard checkpoint compliance tracking
  • Tailgating detection — alerts when two card reads occur in rapid succession at one door
  • After-hours access correlation — flags access events outside normal operating hours
  • Security incident log with video clip link where camera integration exists
  • Access card suspension workflow — immediate deactivation on security incident
