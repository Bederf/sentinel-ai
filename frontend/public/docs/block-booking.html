Block Booking Module

Conference Room Ghost Booking Detection & Automated Cleanup

Add-on

Overview

The Block Booking Module detects "ghost bookings" — conference rooms that are reserved but never used — by cross-referencing HVAC occupancy sensors and desk booking system data against the room's calendar reservation. Ghost bookings waste hot-desking real estate and inflate cleaning costs. The module automatically identifies them, notifies bookers, and frees up the space for others to book.

Capabilities

  • Ghost booking detection — flags rooms booked but unoccupied for > 80% of reserved time
  • Automated cancellation — unoccupied rooms released back to the booking pool after no-show window (15 min)
  • Booker notification — Telegram/email alert to the person who made the ghost booking
  • Pattern tracking — identifies individuals or teams who habitually over-book rooms they don't use
  • Hot-desk utilization reports — desk booking vs. actual attendance per floor/zone
  • Dynamic space release — occupied rooms near capacity trigger automatic desk reassignment
  • No-show penalty mode — optional automatic charging of no-show costs to department cost centres
  • Email intake integration — processes booking cancellation emails via natural language classification

Ghost Booking Detection Logic

Integration

Block Booking reads HVAC occupancy data from HVAC module and desk booking events from Space Optimization. Notifies bookers via Notifications. Works with Maintenance to flag persistent HVAC sensor failures that cause false ghost booking alerts.
